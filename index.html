Why \(\sum_{n=1}^{\infty} \frac{1}{2^n} = 1\) Does NOT Solve Zeno’s Paradox!

1. Tail-End Problem (Slides 17–18): In Figure 1, the walker stands at \(0\) facing the infinite tail end \(\dots, \frac{1}{8}, \frac{1}{4}, \frac{1}{2}, 1\)—there is no “first step.” Reversing the path (Figure 2: \(\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \dots\)) creates the mirror problem: there is no “last step”!

2. Circular Reasoning with Time & Speed (Slide 19): Claiming an infinite series of steps takes finite time assumes constant speed = distance / time. Yet Zeno rejects the distance part itself—assuming motion occurs to “prove” motion is possible is circular!

3. Quantized Space & Physics (Slide 21, Footnote 1): Zeno’s paradox challenges the infinite divisibility of physical space. If space is discrete below the Planck scale (\(\sim 10^{-33}\text{ cm}\))—as explored in loop quantum gravity (Chamseddine, Connes & Mukhanov, J. High Energy Phys. 2014)—motion decomposes into a large but finite number of irreducible steps, dissolving the paradox.

Sequences vs. Sets & Function View (Slide 5)

A sequence is an ordered list of real numbers (finite or infinite). Unlike a set, order matters and numbers may repeat: \(\langle 1, 2, 3 \rangle \neq \langle 1, 3, 2 \rangle\), even though both form the same set \(\{1, 2, 3\}\).

Using natural numbers \(\mathbb{N} = \{0, 1, 2, 3, \dots\}\), any infinite sequence \(\{a_n\}_{n=0}^{\infty}\) is the range of a function \(f : \mathbb{N} \to \mathbb{R}\): (1)

\[ f(n) = a_n \]
Definition ( 1.1 ) — Limit of an Infinite Sequence

A real number \(L\) is the limit of \(\{a_n\}\), written \(\displaystyle \lim_{n \to \infty} a_n = L\) or \(a_n \to L\), if for any given \(\varepsilon > 0\) there exists an integer \(N\) such that (2)

\[ |a_n - L| < \varepsilon \quad \text{for all } n > N. \]

If \(L\) exists, \(\{a_n\}\) converges to \(L\) (convergent); otherwise it is divergent. By (1), limit laws and L’Hôpital’s Rule for \(f(x)\) as \(x \to \infty\) apply directly!

Definition ( 1.2 ) — Sum of an Infinite Series

The sum of an infinite series \(\displaystyle \sum_{n=0}^{\infty} a_n = a_0 + a_1 + a_2 + \cdots\) is (4)

\[ \sum_{n=0}^{\infty} a_n = \lim_{n \to \infty} s_n, \quad \text{where } s_n = \sum_{k=0}^{n} a_k \;\; (n \ge 0) \]

is the sequence of partial sums. The series converges to \(s\) if \(\{s_n\} \to s\), and diverges if \(\{s_n\}\) diverges.

Theorem ( 1.1 ) — Geometric Progression (Slides 14–15)

For \(s_n = a + ar + \cdots + ar^n\), subtracting \(r s_n\) cancels interior terms: \(s_n - r s_n = a - a r^{n+1} \implies s_n = \dfrac{a(1 - r^{n+1})}{1 - r}\). Since \(r^{n+1} \to 0\) when \(|r| < 1\), for \(a \neq 0\) and \(|r| < 1\): (6)

\[ \sum_{n=0}^{\infty} a r^n = a + ar + ar^2 + \cdots = \frac{a}{1 - r} \]

2. Power Series & Term-by-Term Calculus

Turn geometric progressions into functions of \(x\), visualize the Interval of Convergence \(|x - c| < R\), and differentiate or integrate term by term.

Lecture Notes 11 • Slides 22–25
Power Series & Geometric Function (Slide 22)

A power series about constant center \(c\) has the form \(\displaystyle \sum_{n=0}^{\infty} a_n (x - c)^n\). Replacing \(r\) by variable \(x\) in the geometric series (\(c = 0\)) yields: (7)

\[ \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots = \frac{1}{1 - x} \quad \text{for } -1 < x < 1. \]

For \(|x| \ge 1\), \(x^n \not\to 0\), so the series diverges by the \(n\)-th Term Test.

Theorem ( 2.1 ) — Term-by-Term Calculus (Slide 24)

If \(\displaystyle f(x) = \sum_{n=0}^{\infty} a_n (x - c)^n\) converges for \(|x - c| < R\), then both (8)

\[ f'(x) = \sum_{n=1}^{\infty} n\,a_n (x - c)^{n-1} \quad \text{and} \quad \int f(x)\,dx = C + \sum_{n=0}^{\infty} \frac{a_n}{n+1}(x - c)^{n+1} \]

converge for \(|x - c| < R\). Crucial Caution: Convergence at the endpoints \(x = c \pm R\) is not guaranteed by Theorem 2.1 and must be checked individually!*

*Footnote 2: Proofs require uniform convergence (Bromwich, An Introduction to the Theory of Infinite Series, 1955).

3. Taylor’s Series, Remainder Bounds & Calculator Algorithms

Match derivatives at \(x = c\) to build Taylor and Maclaurin polynomials, prove convergence via Lagrange’s Remainder \(R_n(x)\), and discover how scientific calculators actually compute \(\sin x\).

Lecture Notes 11 • Slides 26–41
Definition ( 3.1 ) — Taylor’s & Maclaurin’s Series (Slides 26–28)

Repeatedly differentiating \(f(x) = \sum_{n=0}^{\infty} a_n (x - c)^n\) at \(x = c\) forces \(f^{(n)}(c) = n!\,a_n\), so \(a_n = \dfrac{f^{(n)}(c)}{n!}\) (11)

The Taylor’s series of \(f\) at \(c\) (and Maclaurin’s series when \(c = 0\)) are: (12)–(13)

\[ \sum_{n=0}^{\infty} \frac{f^{(n)}(c)}{n!}(x - c)^n \qquad \text{and} \qquad \sum_{n=0}^{\infty} \frac{f^{(n)}(0)}{n!} x^n. \]

⚠️ Warning (Slide 28): Having derivatives of all orders lets us write down Taylor’s series, not guarantee it converges to \(f(x)\)! (Try the \(e^{-1/x^2}\) preset below.)

Theorem ( 3.1 ) — Taylor’s Formula with Remainder (Slides 31–33)

If \(f\) has derivatives up to order \(n+1\) on an open interval \(I\) containing \(c\), then for each \(x \in I\): (14)

\[ f(x) = \underbrace{\sum_{k=0}^{n} \frac{f^{(k)}(c)}{k!}(x - c)^k}_{P_n(x)} + R_n(x), \quad \text{where } R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x - c)^{n+1} \]

for some \(\xi\) strictly between \(c\) and \(x\) (15). Thus \(P_n(x) \to f(x)\) if and only if \(\displaystyle \lim_{n \to \infty} R_n(x) = 0\).

Proof Idea via Rolle’s / Mean Value Theorem (Slides 32–33)
Fix \(x \in I\) (\(x \neq c\)) and define constant \(M\) by \(f(x) = P_n(x) + M(x - c)^{n+1}\). Define auxiliary function \(g(t)\) for \(t\) between \(c\) and \(x\): \[ g(t) = f(x) - \sum_{k=0}^{n} \frac{f^{(k)}(t)}{k!}(x - t)^k - M(x - t)^{n+1}. \] Then \(g(c) = 0\) (by choice of \(M\)) and \(g(x) = 0\) (direct substitution). Differentiating in \(t\) telescopes all interior sum terms, leaving \[ g'(t) = -\frac{f^{(n+1)}(t)}{n!}(x - t)^n + (n+1)M(x - t)^n. \] By Rolle’s Theorem, \(g'(\xi) = 0\) for some \(\xi\) strictly between \(c\) and \(x\), yielding \(M = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}\).

Lab 3B Inside Your Scientific Calculator: Range Reduction & CORDIC vs. Maclaurin

Slides 39–41 • Hardware Computing Deep-Dive
Why don’t pocket calculators just plug \(x\) into Maclaurin’s series? (Slides 39–41)
1. Large \(x\) causes huge intermediate powers \(x^{2k+1}\) and catastrophic cancellation before factorial growth wins.
2. Early calculator chips (e.g., HP-35, 1972) lacked fast hardware multipliers! Instead, Jack Volder’s CORDIC algorithm (1959) rotates a unit vector by pre-stored angles \(\alpha_i = \arctan(2^{-i})\) using only bit-shifts (\(2^{-i}\)) and additions.†

†Footnote 3 (Slide 41): Modern FPUs combine argument reduction, lookup tables, and minimax/CORDIC schemes — see J.-M. Muller, Elementary Functions: Algorithms and Implementation (3rd ed., Birkhäuser, 2016).
